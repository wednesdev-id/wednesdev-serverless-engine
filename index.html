Architecture Deep-Dive
⚡

Near-Zero Cold Starts (< 1ms)

Leverages Wasmtime Component Model with precompiled guest instances. Eliminates container VM boot overhead entirely.

🚀

HTTP/3 & QUIC Built-In

First-class UDP multiplexing and 0-RTT handshakes via quinn and rustls. Native HTTP/1.1, HTTP/2, and HTTP/3 support out of the box.

🛡️

Zero-Knowledge Encrypted Artifacts

Confidential execution model with cryptographic artifact verification, atomic registry swaps, and zero host-guest leakage.

🌐

Polyglot Language SDKs

First-class guest tooling and bindings for Rust, TypeScript/JavaScript (via ComponentizeJS), and Python (via Componentize-Py).

📋

Declarative Multi-Function Manifest

Configure routing, per-function memory bounds (1-2048 MB), timeouts, and concurrency policies seamlessly in wednes.yaml.

📊

Production-Grade Sandboxing

Epoch-based execution trapping, StoreLimits linear memory enforcement, Axum admission semaphore, and zero-privilege host boundaries.

Why Wednes Serverless Engine? ​

Traditional container-based serverless architectures suffer from high cold start latencies (200ms–2s), heavyweight memory footprints (64MB–256MB baseline per replica), and sluggish scaling behavior.

Wednes Serverless Engine re-architects serverless computing from the ground up on WebAssembly and WASI Component Model standards:
